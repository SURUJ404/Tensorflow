# Chapter 6 - Convolutional Neural Networks

## What you'll build
A CNN that classifies clothing images (Fashion-MNIST) - and see *why* it wins on images.

## Concepts
- `Conv2D` filters slide over the image, keeping spatial layout
- `MaxPooling2D` compresses & stabilizes
- Feature map visualization (what the first conv layer detects)
- Why CNNs beat Dense nets on images (shared weights, locality)

## Files
- `06-Convolutional-Neural-Networks.ipynb`

## Expected result
~91-93% test accuracy on Fashion-MNIST (~7-10pp above a plain Dense net).
