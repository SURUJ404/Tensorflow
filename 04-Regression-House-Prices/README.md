# Chapter 4 - Predicting House Prices (Regression)

## What you'll build
Predict a house's price (a continuous number) from numeric features.

## Concepts
- Regression = 1 linear output unit, `mse` loss, `mae` metric
- Z-score normalization of mixed-scale features
- K-fold cross validation for an honest error estimate
- Data is generated from scratch with `numpy` (we know the ground-truth rule!)

## Files
- `04-Regression-House-Prices.ipynb`

## Expected result
Model recovers the hidden pricing rule within ~ a few $k of MAE.
