# Chapter 12 - Generative Adversarial Networks (GANs)

## What you'll build
A generator + discriminator pair trained in a minimax game; the generator learns to forge MNIST digits.

## Concepts
- Generator: noise -> fake image
- Discriminator: real vs fake
- Alternate losses (binary cross-entropy on both sides)
- Why GANs produce sharp images while VAEs produce smooth ones

## Files
- `12-Generative-Adversarial-Networks.ipynb`

## Expected result
After ~10 epochs you see digit-like shapes emerging.
