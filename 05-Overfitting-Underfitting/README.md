# Chapter 5 - Overfitting and Underfitting

## What you'll learn
Make the two classic failure modes *visible*, then fix them.

## Diagnosis
- **Overfit signature**: train loss keeps dropping, validation rises after an epoch.
- **Underfit signature**: both train & validation stay poor.

## Fixes
- Reduce model capacity
- L2 regularization (weight decay)
- Dropout
- Early stopping via callbacks
