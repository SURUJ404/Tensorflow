# Chapter 2 - Binary Classification

## What you'll build
A model that decides whether an IMDB movie review is positive or negative.

## Concepts
- Binary output = one unit + `sigmoid`
- Loss = `binary_crossentropy`
- Turning text into fixed-length integer sequences (`pad_sequences`)
- Reading prediction probability near 0 (negative) / 1 (positive)

## Files
- `02-Binary-Classification.ipynb`

## Expected result
~85-88% test accuracy (basic embedding+flatten; the RNN chapter improves this).
