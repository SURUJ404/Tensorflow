# Chapter 9 - Text Generation with LSTM

## What you'll build
A character-level LSTM trained on a small public-domain corpus that writes new text.

## Concepts
- Predicting the *next character* distribution from previous ones
- One-hot encoding of characters
- `temperature` sampling (greedy vs creative)
- The same pipeline scales to books/Shakespeare

## Files
- `09-Text-Generation-LSTM.ipynb`

## Try it
Lower temperature = more coherent. Higher = more surprising.
