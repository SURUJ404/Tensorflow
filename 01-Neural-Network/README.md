# Chapter 1 - Build Your First Neural Network

## What you'll build
A feed-forward network that classifies handwritten digits (MNIST) into 0-9.

## Concepts
- Layers, weights, activation functions
- `Flatten`, `Dense`, `Dropout`, `softmax`
- Training loop: `model.fit` minimizing `sparse_categorical_crossentropy`
- Reading the loss/accuracy curves

## Files
- `01-Neural-Network.ipynb` - the full lesson

## Expected result
~97-99% test accuracy on MNIST after 10 epochs on CPU.
